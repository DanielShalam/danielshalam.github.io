The tracked LaTeX source is [`cv/CV_Daniel.tex`](cv/CV_Daniel.tex). The website serves the generated [`CV_Daniel.pdf`](CV_Daniel.pdf). AltaCV v1.7.4 is vendored under `cv/` from upstream commit `91373530c55843533a4de12a29d28896f9b14c0d`; see [`cv/LICENSE.altacv.md`](cv/LICENSE.altacv.md).

Regenerate the PDF with [Tectonic](https://tectonic-typesetting.github.io/) installed:

```sh
make cv
```
